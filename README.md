<h2 id="about">📌 Sobre o Projeto</h2>

Este projeto é uma solução para o desafio **Product List with Cart** do **Frontend Mentor**.  
O objetivo foi desenvolver uma interface moderna e responsiva que permita ao usuário visualizar produtos, adicioná-los ao carrinho e finalizar um pedido com uma experiência clara e intuitiva.

🔹 **Principais pontos do projeto:**

- Gerenciamento de estado do carrinho
- Atualização dinâmica de quantidades
- Modal de confirmação de pedido
- Layout responsivo
- Estilização modular com SCSS

---

<h2 id="features">✨ Funcionalidades</h2>

- **Listagem de Produtos**
  - Exibição dinâmica dos produtos a partir de um arquivo JSON
  - Layout adaptável para diferentes tamanhos de tela

- **Carrinho de Compras**
  - Adicionar e remover produtos
  - Aumentar e diminuir a quantidade de itens
  - Cálculo automático do total do pedido

- **Modal de Confirmação**
  - Exibição de um modal centralizado ao confirmar o pedido
  - Fundo escurecido com opacidade (overlay)
  - Opção de iniciar um novo pedido

- **Experiência do Usuário**
  - Estados de hover e focus
  - Interface limpa e acessível
  - Feedback visual para ações do usuário

<h2 id="started">🚀 Como Executar o Projeto</h2>

### Pré-requisitos

- Node.js (versão LTS recomendada)
- Gerenciador de pacotes (npm ou yarn)

### Passo a Passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/RafaelHDSV/Product-list-with-cart.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd product-list-with-cart
   ```

3. Instale as dependências:

   ```bash
   yarn
   ```

4. Execute o projeto:

   ```bash
   yarn dev
   ```

5. Abra no navegador:
   ```
   http://localhost:5173
   ```
